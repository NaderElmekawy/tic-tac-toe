# Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built with Python using Object-Oriented Programming (OOP).

## Concepts Used

- Classes and Objects
- Encapsulation
- Methods
- Loops
- Conditional Statements
- User Input
- Lists
